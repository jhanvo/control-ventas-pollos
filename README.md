Control de Ventas de Pollos-Dashboard en Excel

Descripción
proyecto de análisis y control de ventas desarrollado en Microsoft Excel para un negocio de venta de pollos de engorde.
El Dashboard permite visualizar información sobre las ventas, los pagos recibidos y las deudas pendientes, facilitando el seguimiento de las opciones del negocio.

Funcionalidades
-Registro de los compradores y las ventas
-Cálculo del valor de cada pollo con su respectivo peso en libras
-Seguimiento de los pagos realizados y los pagos pendientes
-Dashboard con el Resumen de ventas, Dinero recibido, Deudas, Total de pollos vendidos
-Dashboard con grafico del pagos y deudas
-Organización de la información facilitando la toma de decisiones

Herramientas utilizadas
-Microsoft Excel
-Fórmulas y funciones de Excel
-Tablas y gráficos
-Tablas dinámicas

Datos de demostración
Este repositorio contiene datos ficticios como parte de la demostración, creada con fines de presentación para mi portafolio.

Objetivo del proyecto
Aplicar conocimientos en Excel y en análisis de datos para construir una herramienta práctica ante el seguimiento de ventas y el control financiero
de un pequeño negocio en el campo.

Autor
Proyecto desarrollado como parte de mi portafolio en tecnología y análisis de datos.
